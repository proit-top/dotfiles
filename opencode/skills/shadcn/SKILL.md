# shadcn/ui

Если нужно создать UI-компонент (кнопки, формы, диалоги):
1. Не пиши компонент с нуля.
2. Выполни в терминале: `npx shadcn@latest add <component-name>`
3. Импортируй созданный компонент из `@/components/ui/`.
